# Test matrix

Where each case from [AGENT_PROMPT.md §12](../AGENT_PROMPT.md) is tested.
Paths are under `packages/<pkg>/test/`. "Per platform" cases use the
sanitized fixtures in `packages/extension/test/fixtures/<platform>/`.
Backend suites run against real Postgres 16 and Redis 7 with a fake GitHub.

| #   | Case                                                                     | Tests                                                                                                                                                                                                                                                                                                                                                                           |
| --- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Accepted → upload triggered                                              | `extension/leetcode.e2e`, `codeforces.e2e`, `codechef.e2e` (byte-exact upload, right commit and folder); `backend/extension.e2e` (through the backend)                                                                                                                                                                                                                          |
| 2   | WA / CE / RE / TLE / MLE / pending never upload                          | `leetcode.parse` (pending, started, WA, CE, RE, TLE, MLE), `codeforces.parse` (testing, queued, WA, TLE, MLE, RE, CE, skipped, hacked), `codechef.parse` (queued, partial, WA, TLE, RE, CE, error, judge error); adapters: "does not upload a %s verdict", "does not emit when details say…"; `handler`: "never queues %s submissions"; `api`: "rejects what must never upload" |
| 3   | Repeated events → no duplicate                                           | `runner`: "forwards each submission once despite re-emits"; `outbox`: "enqueues once per submission"; `leetcode.e2e`: "re-emitted events for one submission produce one commit"; `core/dedup` and `backend/db`: idempotency                                                                                                                                                     |
| 4   | Second accepted follows the window                                       | `core/dedup`: "skips a second accepted solution…"; `core/policies` (all policies); `leetcode.e2e`: "skips a second accepted solution the same day…"; `backend/db`: "skips within the window…"                                                                                                                                                                                   |
| 5   | New window → uploads again                                               | same tests as 4 ("uploads in the next", "uploads again the next day"); `core/policies` boundary rows                                                                                                                                                                                                                                                                            |
| 6   | Different problems independent (same title across platforms)             | `core/dedup`: "keeps problems and platforms independent, even with equal titles or keys"; `core/policies`: "a success on another platform or problem never blocks"; `shared/slug`: "keeps same titles on different platforms in different folders"                                                                                                                              |
| 7   | Source preserved byte-exactly (CRLF, tabs, trailing spaces, unicode)     | `shared/hash`; `shared/schemas`: "preserves source code exactly"; platform e2e tests (hash compare); `codeforces.parse`: "keeping CRLF"; `backend/db`: "round-trips a job and its source byte for byte"                                                                                                                                                                         |
| 8   | Correct extension per language (incl. platform names)                    | `shared/language` (38-row table incl. "GNU G++20 13.2 (64 bit, winlibs)", "PyPy 3-64", "Kotlin 1.9", "Python 3"); `uploader`: "keeps different languages in separate files"; `extension/languageOverrides`                                                                                                                                                                      |
| 9   | File under `data/` with the exact commit message                         | `shared/commitMessage`; `shared/slug`: "builds the default path under data/"; `core/uploader`: "writes solution and metadata in one commit with the exact message"                                                                                                                                                                                                              |
| 10  | Failed upload not marked uploaded; retry without duplicate commit        | `core/worker`: "a retry after a transient failure produces exactly one commit", "a retry after GitHub already applied the commit…"; `core/dedup`: "a permanently failed job releases the reservation"; `localUploader`: "retries a failed job manually without duplicating the commit"; `backend/queue`: "retries a 5xx… without a duplicate commit"                            |
| 11  | Concurrent identical events → exactly one job                            | `core/dedup`: "collapses concurrent identical events into one job", "admits exactly one of many concurrent submissions"; `outbox`: "collapses concurrent identical events"; `backend/db`: 20 concurrent identical → one job, 20 concurrent submissions → one queued; `backend/queue`: 10 concurrent enqueues → one queue job                                                    |
| 12  | Worker restart / Redis flush → recovered                                 | `backend/queue`: "recovers jobs after Redis loses its data and after a crash mid-upload", "re-claims an UPLOADING row…", "finishes the active upload before a graceful shutdown"; `localUploader`: "recovers jobs interrupted mid-upload by a service-worker kill"; Compose run (stage 6): `FLUSHALL` with the worker stopped                                                   |
| 13  | Service worker restart → outbox and dedup state preserved                | `outbox`: "survives a service worker restart"; `core/kvJobStore`: "persists across instances (service worker restart)"; `settings`: "persists across instances"                                                                                                                                                                                                                 |
| 14  | Missing source / unsupported language → clear error, no upload           | `shared/schemas`: "rejects empty source code"; `core/worker`: "unsupported language fails clearly before touching GitHub", "fails jobs whose source was already purged"; adapters: "emits nothing when the code cannot be fetched"; `shared/language`: "throws a clear error… instead of using .txt"                                                                            |
| 15  | 401 → NEEDS_AUTH and resume; 429 delayed; 5xx bounded; 404/403 permanent | `core/errors` (each status); `core/worker`: "needs auth without a token, and resumes…", "delays on rate limits without burning attempts", "retries 5xx with backoff and gives up after the max attempts", "missing repo or branch is permanent", "403 without write access is permanent"; `backend/queue`: 429, 502, 401 cases                                                  |
| 16  | Existing-file conflict → suffix path; identical → no commit              | `core/uploader`: "never overwrites a different solution; uses the submission-id path", "makes no commit when identical content is already there", "refuses when even the submission-id path holds different content"                                                                                                                                                            |
| 17  | Ref-update conflict → rebuild and retry                                  | `core/uploader`: "rebuilds on a ref conflict without losing the other change", "gives up after bounded ref conflicts"                                                                                                                                                                                                                                                           |
| 18  | Timezone and calendar boundaries                                         | `shared/period` (IST midnight, NY DST both ways, skipped midnight, leap day, week start, year boundary, month ends); `core/policies` (every policy ±1 ms at its edges)                                                                                                                                                                                                          |
| 19  | Force bypasses the window, not accepted/source checks                    | `core/dedup`: "force bypasses the window…", "force never bypasses the accepted/source checks", "re-validates the stored submission before queueing, even when forced"; `policies.e2e`, `backend/api`, `backend/extension.e2e` force cases                                                                                                                                       |
| 20  | Slug/path sanitization and traversal                                     | `shared/slug` (traversal, absolute, fullwidth, RTL override, empty titles, bad keys and extensions, submission-id traversal)                                                                                                                                                                                                                                                    |
| 21  | Secrets never in logs / errors / metadata                                | see [SECURITY.md](SECURITY.md): `backend/api` log check, `foundation` logger, `core/errors` redaction, `core/worker` lastError, `core/uploader` metadata and Authorization header                                                                                                                                                                                               |
